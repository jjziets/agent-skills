# Source Basis

This register records the sources that informed the distilled requirements
review rules. It is not a source summary and it is not a license grant. Runtime
agents must use the distilled TraceWeaver rules, not copied source text.

## Runtime Boundary

- Use these sources only to justify the existence of the distilled model.
- Do not quote licensed source text in runtime findings.
- Do not copy source tables, source diagrams, page layouts, or examples.
- Mermaid diagrams in runtime material must be new TraceWeaver diagrams.
- Public citations may point to official public pages, but the rule text must
  remain original.

## Update Rule

When adding a new source, record:

- source ID
- exact source name
- access type
- what operational rule family it informed
- whether it is public, licensed/internal, or controlled/purchase-only
- any reuse restriction relevant to runtime agent material
